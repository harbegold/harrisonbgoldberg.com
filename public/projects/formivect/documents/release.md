# Release and availability

## Personal preview

Formivect 0.2.0 is an unsigned personal preview tested on Windows. It includes Windows/Mac installer files, but Mac native execution remains unverified. It requires Fusion, Python and the chosen AI client. The preview has no Formivect account or payment screen; provider allowances and external prerequisites still apply.

The application source, installers, full transfer ZIPs, private histories and original internal pitch are not part of this public portfolio release. There is no public commercial price, support commitment, revenue claim or launch-date promise.

## Public portfolio

This page, four reviewed PDFs, selected interface/native images, explanatory diagrams, Markdown/HTML, feature data and website adapters form the publishable release. The public-only ZIP contains exactly that selected folder. Rights are reserved; inclusion of documentation is not a software or model license.

## Potential software release

Public distribution, licensing, support, tested updates, migrations, backups, telemetry and production rollback are future decisions. Proposed local/hybrid/hosted deployments and owned-model inference must be validated separately.
