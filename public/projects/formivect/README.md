# Formivect

## Engineering AI Workspace

**Personal preview 0.2.0 verified on Windows. Independent platform proposed.**

A local Fusion bridge connects AI to actual CAD, project histories and controlled native execution. The proposed platform grows toward editable CAD, analysis/manufacturing, durable agents, revision-linked evidence and an owned engineering model.
