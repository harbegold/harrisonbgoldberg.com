## Evidence and revision notes

- **Physical prototype:** previously published September 2026 Bitzy V1 demo, 720 x 1280, 30 seconds, silent. Assembly footage includes sped-up segments. Still frames are extracted from this video without changing the pictured hardware.
- **Historical studies:** earlier six-axis CAD animation and side-elevation/wrist sketches. Their 729 mm zero-pose reference and original component labels remain historical, not a current five-axis dimensional audit.
- **Gripper Rev B:** native CAD release documentation and actual assembly/mechanism views; 108 named parameters, 84 components, nine native travel checks and 31 printable shapes/coupons.
- **Screwdriver R2:** September 9 native release documentation and actual assembly/mechanism/cartridge views; 136 parameters, 67 components and 23 printable shapes/coupons.
- **Controls:** September 9 replay/backstop record, including 28 Python checks and JavaScript control/replay checks. These are reported historical verification results, not new physical tests.
- **Budget:** selected item prices from the August 31/September 1 power/wiring master list. Current total build cost is not reconciled.

Assembly and tooling PDFs are newly composed public review documents using these existing images, sketches and records. They are not newly released native fabrication drawings. No whole-arm FEA or measured accuracy dataset is represented.

## Release boundary

Only this public folder belongs in a website or public release. Editable CAD, neutral geometry, meshes, manufacturing files, wiring schedules, parameter registers, control source, calibration/saved positions, internal logs and full engineering archives are excluded. The public images and selected sketches remain copyable.

AI-assisted workflows supported the creation of this project.
