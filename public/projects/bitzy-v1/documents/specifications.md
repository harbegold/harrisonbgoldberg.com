# Bitzy V1 public specifications

Nominal values identify their revision and are separate from measured performance.

| Item | Public reference |
|---|---|
| Project stage | Built prototype; control refinement and physical qualification ongoing. |
| Project start | June 2026; current public review September 10, 2026 |
| Arm architecture | Five controlled arm axes; six arm servos because the shoulder uses a synchronized pair |
| Current servo record | DS5160SSG shoulder pair and elbow; MS24 replacements reported at base yaw and both wrist axes |
| Motion/control | ESP32-S3, PCA9685, Python desktop bridge and browser controller; MATLAB/Python kinematics |
| Nominal reach reference | Approximately 475 mm; design reference, not an independently measured workspace |
| Payload objective | 500 g object plus tool mass; target only, no qualified load envelope |
| Shared tool interface | Original star and four-screw mounting interface retained |
| Gripper Rev B | 108 named parameters, 84 CAD components; 2-26 mm nominal soft-jaw opening, 12 mm travel per jaw |
| Gripper packaging | 74 x 73 mm nominal case; PETG-CF case, replaceable TPU sleeves; 25 product shapes and six fit coupons |
| Screwdriver R2 | 136 named parameters, 67 CAD components; 4:1 external reduction, 3 mm guided axial compliance |
| Screwdriver packaging | 80 x 70 mm nominal case; 12 product prints and 11 fit ladders; 287.7 g estimated installed mass, 340 g planning allowance |
| Tool attachment | Manual exchange through the common mounting interface; automatic docking is future work |
| Physical evidence | 30-second silent prototype video shows module assembly and coordinated motion |
| Historical reference | Earlier six-axis animation and 729 mm zero-pose sketches are design history, not current hardware measurements |
| Budget record | No verified total V1 build cost; dated power/wiring procurement entries are partial and include owned/deferred items |
